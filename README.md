# plastic-waste-management
Plastic Waste Management System ♻️

Description

This project is developed using C programming to calculate plastic waste generated by households, schools, and shops. It provides suggestions for reducing, reusing, recycling, and segregating plastic waste.

Features

- Calculates total plastic waste.
- Displays a waste report.
- Provides waste management suggestions.
- Supports environmental awareness.

Technology Used

- C Programming

How to Run

1. Compile the code:
   "gcc plastic_waste.c -o plastic_waste"
2. Run the program:
   "./plastic_waste"

Project Goal

To promote proper plastic waste management and protect the environment.
